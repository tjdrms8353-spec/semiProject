## 적용 내용

Docker와 Compose를 설치하고 프론트엔드(Nginx)와 백엔드를 한 EC2에서 실행했다. 프론트엔드는 /api 경로로 백엔드를 호출한다. 백엔드 8000 포트는 외부에 공개하지 않는다. 빌드 메모리 보조를 위해 4GiB 스왑을 추가했다.

개인 설정은 deploy/ec2/.env에 별도 저장하고 접근 권한을 제한했다. EC2 인증 SECRET_KEY는 별도로 생성했다. Docker 빌드에서 비밀 설정·임시 파일·Blender 원본을 제외하도록 .dockerignore를 추가했다. 관리자 비밀번호 해시의 달러 문자가 보존되도록 Compose env_file에 format: raw를 설정하고 실행 중인 컨테이너 값까지 비교했다.

```sh
cd /home/ubuntu/onfit/Semiproject-front
sudo docker compose -f compose.ajb.yaml -f deploy/ec2/compose.https.yaml ps
sudo docker compose -f compose.ajb.yaml -f deploy/ec2/compose.https.yaml logs --tail 50
sudo docker compose -f compose.ajb.yaml -f deploy/ec2/compose.https.yaml restart
```
